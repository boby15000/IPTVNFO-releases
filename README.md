# IPTVNfo-releases
IPTVNFO — lecteur IPTV gratuit pour Android TV et smartphone. Ajoutez vos codes Xtream ou une playlist M3U : chaînes, films et séries rangés automatiquement par genre, replay, radios, guide TV, profils enfants, Chromecast. Ce dépôt contient uniquement les versions à télécharger (APK).
